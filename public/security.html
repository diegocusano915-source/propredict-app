Encryption & Data Protection

Every piece of data you send to ProPredict is protected by multiple layers of encryption — both in transit and at rest.

TLS 1.3 Encryption

All connections to ProPredict use TLS 1.3, the most secure encryption protocol available. Your data is unreadable to anyone intercepting the connection.

bcrypt Password Hashing

Your password is never stored in plain text. We use bcrypt with a high work factor — even if our database were compromised, your password remains secure.

Encrypted at Rest

All user data stored in Supabase is encrypted at rest using AES-256. Your personal information, subscription data, and activity logs are fully protected.

Zero-Knowledge Architecture

We never store your full payment details. Paystack processes all payments, and we only receive confirmation tokens and subscription status.

Payment Security

Your payment information is handled by industry-leading processors with the highest security certifications.

  • PCI DSS Level 1 Compliance — Paystack is certified to the highest payment security standard.
  • No Card Storage — ProPredict never sees or stores your credit card, bank account, or crypto wallet details.
  • 3D Secure Authentication — Additional verification layer for card transactions to prevent fraud.
  • Crypto Payment Security — USDC and USDT payments use secure wallet addresses with multi-signature protection.
  • Fraud Monitoring — Real-time transaction monitoring to detect and block suspicious activity.

Account Protection

Email Verification

All new accounts must verify their email address before gaining full access. This prevents unauthorized account creation.

Session Management

Sessions expire after 30 days (or 7 days if "Remember Me" is unchecked). You can view and revoke active sessions.

Login Alerts

We notify you via email when a new device or location logs into your account. Suspicious activity triggers immediate alerts.

Strong Password Policy

Passwords must be at least 8 characters with uppercase, lowercase, numbers, and special characters. We enforce this on registration.

Infrastructure Security

  • Supabase Secure Hosting — Our database runs on Supabase with enterprise-grade security, firewalls, and network isolation.
  • Render Cloud Infrastructure — Application hosted on Render with DDoS protection and automatic security patching.
  • Regular Security Audits — We conduct quarterly security reviews and penetration testing.
  • Automated Backups — Database backups occur daily with point-in-time recovery capability.
  • Rate Limiting — API endpoints are rate-limited to prevent brute force and denial-of-service attacks.
